1. Overview
------------------------------------------------------------------------------
Grafana Loki is a horizontally-scalable, highly-available log aggregation system. 
This document outlines how to deploy Grafana Loki locally via Docker Compose and 
forward logs from the `hello-devops` container / Nomad service tasks to Loki for 
centralized log querying and visualization.

2. Infrastructure as Code: Runnable Configs
------------------------------------------------------------------------------
The `monitoring` directory contains the actual runnable configurations for the stack:
- `loki-config.yml`: Configuration for the Loki server.
- `promtail-config.yml`: Configuration for Promtail to scrape Docker container logs.
- `docker-compose.yml`: Docker Compose file to bring up Loki, Promtail, and Grafana in a single command.

3. Running the Stack
------------------------------------------------------------------------------
To bring up the entire monitoring stack, navigate to the `monitoring/` directory and run:

    docker-compose up -d

This will start:
- Loki on port 3100
- Promtail to collect and push logs to Loki
- Grafana on port 3000

4. Forwarding Docker / Nomad Container Logs to Loki
------------------------------------------------------------------------------
Option A: Using Docker Loki Logging Driver
docker plugin install grafana/loki-docker-driver:latest --alias loki --grant-all-permissions
docker run --log-driver=loki --log-opt loki-url="http://localhost:3100/loki/api/v1/push" --log-opt loki-batch-size="400" hello-devops:latest

Option B: Accessing Grafana Dashboard UI
Navigate to http://localhost:3000 (no login required for Admin), and add Loki Data Source (http://loki:3100).

5. Commands to View & Query Logs
------------------------------------------------------------------------------
To query Loki HTTP API directly using curl:
curl -G -s "http://localhost:3100/loki/api/v1/query_range" --data-urlencode 'query={container_name="hello-devops"}' | jq

To view live log streams using LogCLI:
logcli --addr="http://localhost:3100" query '{container_name="hello-devops"}'
